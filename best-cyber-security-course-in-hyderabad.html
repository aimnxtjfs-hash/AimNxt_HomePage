What is Cyber Security - and What Does a Cyber Security Professional Do?

Cyber security is the practice of protecting computer systems, networks, applications, and data from unauthorized access, cyberattacks, and damage.

It covers both defensive operations - monitoring and responding to active threats - and offensive operations - testing systems to find vulnerabilities before attackers do.

Every organisation that handles digital data needs trained cyber security professionals to protect its infrastructure.

What Does a Cyber Security Professional Do Day-to-Day?

The day-to-day work of a cyber security professional depends on which track they work in. Defensive security professionals monitor dashboards, investigate alerts, contain incidents, and analyse threats in real time.

Offensive security professionals simulate attacks on live systems - using the same techniques a real attacker would use - and produce reports that help organisations fix weaknesses before they are exploited.
