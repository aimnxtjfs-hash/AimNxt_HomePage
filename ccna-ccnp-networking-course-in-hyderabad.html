Course Curriculum Networking (CCNA & CCNP)

Module 1: CCNA - Implementing and Administering Cisco Solutions
▾

Implementing and Administering Cisco Solutions (CCNA) version 2.0 teaches learners how to install, operate, configure, and verify basic IPv4 and IPv6 networks.

  • Network Fundamentals
  • Network Access
  • IP Connectivity
  • IP Services
  • Security Fundamentals
  • Automation and Programmability

This module prepares students for the Cisco Certified Network Associate (200-301) exam.

Module 2: CCNP - Cisco Enterprise Network Core & Advanced Technologies
▾
  • Enterprise Network Architecture & Design
  • Virtualization (VLAN, VRF)
  • Infrastructure (L2/L3, OSPF, EIGRP, QoS)
  • Network Assurance (SNMP, NetFlow, DNAC)
  • Enterprise Security & Firewalls
  • Wireless Technologies (Cisco & Aruba)
  • Automation & Programmability (SDN, APIs)
  • Professional & Soft Skills Development
Module 3: Enterprise Firewalls (Cisco / Palo Alto / FortiGate)
▾

This module focuses on configuring, troubleshooting, and managing enterprise firewalls with hands-on labs and real-world security scenarios.

  • Firewall concepts and types
  • Cisco ASA configuration (ACLs, NAT, IPS)
  • Palo Alto security policies & threat prevention
  • FortiGate firewall setup and VPNs
  • High availability and clustering
  • Logging, monitoring, and troubleshooting
  • Incident response and simulated attacks
Module 4: Enterprise Wireless Technologies (Cisco / Aruba)
▾

Learn to design, deploy, secure, and optimize enterprise wireless networks using Cisco and Aruba technologies.

  • Wireless standards and enterprise WLAN design
  • Cisco & Aruba access point deployment
  • Wireless LAN controllers (WLC)
  • WLAN security (WPA2/WPA3, WIPS)
  • RF planning and site surveys
  • Wi-Fi 6 and high-density networks
  • Performance monitoring and optimization
Module 5: Soft Skills & Professional Development
▾

This module enhances communication, leadership, and professional skills essential for corporate and enterprise environments.

  • Effective verbal and written communication
  • Teamwork, collaboration, and conflict resolution
  • Leadership, time management, and adaptability
  • Critical thinking and problem-solving
  • Presentation and public speaking skills

  • Cultural awareness and diversity
